# GT6 Logic 内容设计

本文是附属本体内容的设计稿：设计原则、元件清单、工艺机器、进度安排和界面约定。具体产线的点子另见 [`production-ideas.md`](production-ideas.md)，和 GT6CE 的接口约定见 [`integration.md`](integration.md)。

所有内容都还是草案，数值只是起点，要进游戏试玩后再调。

## 一句话定位

GT6 Logic 给 GT6 加两类东西：

- **一批会“跑偏”的工艺机器**：它们有温度、液位、配比这类会随时间变化的状态，偏离合适范围就减产或出事。
- **一批友好的控制元件**：恒温器、浮球开关、定时器、调节阀、指示灯……让玩家不用懂电路也能把这些机器控制住。

目标是让 GT6 以“自动化最夸张”出名，同时不让它变得更难上手。

## 设计原则

### 1. 用生活里的东西命名，不用电路术语

玩家面对的是“恒温器”“浮球开关”“厨房定时器”，不是“施密特触发器”“RS 锁存器”“单稳态电路”。现实中的工厂控制本来就是这些东西，GT6 的玩家也大多见过。

| 内部原理 | 玩家看到的名字 | 玩家怎么理解 |
|---|---|---|
| 带回差的比较器 | 恒温器 / 浮球开关 | 低于下限就开，高于上限就关 |
| 单稳态 / 延时 | 延时继电器 | 收到信号后等几秒再动作 |
| 振荡器 | 节拍器 / 定时器 | 每隔多久响一次 |
| 计数器 | 计数器 | 数到多少就停 |
| 比例控制 | 自动调节阀 | 越热，冷却水开得越大 |
| 与 / 或 | 联锁开关 | 两个条件都满足才开 |

电路术语只出现在高级元件的说明里，给想深入的玩家看。

### 2. 一个方块解决一个常见问题

最常见的需求，必须能用**一个方块**解决：贴在机器上，打开界面设两个数，完事。不需要拉线，不需要组合别的元件。

- 恒温器直接贴在机器上读温度，同时直接控制相邻的加热器或阀门。
- 浮球开关直接贴在储罐上。
- 信号线和逻辑组合是**可选的进阶玩法**，不是基础玩法的门槛。

### 3. 界面说人话，并且看得见

- 设定值用机器自己的单位：“低于 30 °C 开，高于 35 °C 关”，“液位低于 20% 开”。不让玩家去想“7.25 级信号”。
- 界面里有一条**实时曲线**：过去一段时间的温度或液位走势，加上上下限两条横线。玩家一眼就能看出“它在两条线之间来回走，说明控制住了”，或者“它冲出去了”。
- 方块上有直观的状态显示：指示灯、指针表、数码管。站在机器前就能看懂现在的状态。
- 常用设置提供**预设按钮**，例如“锅炉补水”“蓄电池管理”“发酵罐控温”，点一下自动填好数值。

### 4. 失败要温和，奖励要明显

- 控制不好时，先是**软失败**：减产、出副产物、冒烟、报警声、指示灯变红。给玩家时间反应。
- 真正危险的后果（爆炸、整罐报废）只出现在中后期的高级工艺里，并且有提前预警。
- 提供**安全装置**：泄压阀、紧急冷却、自动停机。装上就不会出大事，代价是损失一些产物。所以控制系统永远是“做得好有奖励”，而不是“做不好就卡关”。
- 爆炸等破坏性后果可以在配置里关掉或换成“机器停机并报警”。

### 5. 先给需求，再给工具

每个控制元件都应该在玩家**刚好需要它的时候**出现：

- 第一台会过热的机器解锁时，恒温器的配方用的正是同一阶段的材料。
- 手册里的每个元件页都从一个具体问题讲起：“发酵罐总是过热？试试恒温器。”而不是从“这个元件的真值表是……”讲起。

### 6. 有趣而无害的东西也欢迎

不是所有元件都要解决问题。报警铃、警示灯、大号拉杆、带标签的按钮、记录纸带的记录仪、控制室用的数码管显示屏……这些让基地看起来像一座真正的工厂，本身就是乐趣。它们不影响平衡，可以早早给出。

## 元件清单

按“玩家什么时候需要它”分档。每个元件都写明它解决什么问题，具体的方块实现参考 [`integration.md`](integration.md)。

### 第一档：入门（一个方块解决问题）

| 元件 | 解决的问题 | 设置项 |
|---|---|---|
| 恒温器 | 机器过热或过冷 | 开启温度、关闭温度、控制加热还是控制冷却 |
| 浮球开关 | 储罐太空或太满 | 开启液位、关闭液位 |
| 蓄电池管家 | 电不够时开发电机，满了就关 | 开启电量、关闭电量 |
| 厨房定时器 | 每隔一段时间做一次某件事 | 间隔、每次持续多久 |
| 指示灯 | 看一眼就知道状态 | 颜色、亮的条件 |
| 报警铃 | 出问题时提醒玩家 | 响的条件、音色 |

这一档的元件可以直接贴在目标机器上读数，并且直接控制相邻方块，不需要信号线。

### 第二档：组合（用信号线连起来）

| 元件 | 解决的问题 |
|---|---|
| 延时继电器 | 让机器按顺序启动，或者信号消失后再保持一会儿 |
| 计数器 | 数到多少个物品或多少次脉冲就停 |
| 联锁开关（与 / 或 / 非） | “水够了**并且**温度够了才开” |
| 信号表 | 用放大镜或表盘看清信号线上的精确值 |
| 补偿中继器 | 抵消信号线长距离传输的衰减 |
| 选择开关 | 手动切换几种工作模式 |

### 第三档：精细控制（给想深入的玩家）

| 元件 | 解决的问题 |
|---|---|
| 自动调节阀 | 按信号强度连续调节流量，而不是只有开和关 |
| 比例控制器 | 偏差越大，调节越猛（对“飞温”这类反应很有用） |
| 配比控制器 | 让两路流量保持固定比例 |
| 程序控温器 | 按时间表升温、保温、降温 |
| 算术模块 | 加、减、缩放、取最大最小，给自己搭控制系统的玩家用 |
| 可编程模块 | 写一行小公式，例如 `clamp(a * 0.5 + b, 0, 15)` |

### 装饰与控制室

数码管显示屏、指针表、记录仪（在界面里画出长时间曲线）、大号拉杆、带标签的按钮、警示灯塔、控制台面板。不影响平衡，早期就能做。

## 执行器

控制元件要有东西可以控制。除了用 GT 自己的机器控制（红石开关机器）之外，本附属提供：

- **电动阀**：开或关一路流体。
- **调节阀**：按信号强度决定通过的流量（0–100%）。这是“模拟信号”第一次真正有用的地方。
- **可调加热器 / 冷却器**：按信号强度决定功率，接 GT 的 EU。
- **可调泵**：按信号强度决定抽送速度。

## 工艺机器

工艺机器负责“制造需求”。共同的规则：

- 都有一个会随时间变化的状态（温度、液位、浓度……），用简单的物理模型模拟：每 tick 的变化 = 输入 − 输出 − 向环境的散失。这样状态有惯性，不会瞬间跳变。
- 都有一个**合适区间**，在区间内正常工作，偏离区间时产率下降，严重偏离时出副产物或停机。
- 都在指定面输出自己的读数（温度、液位）作为精细信号，同时也可以把储罐暴露给本体的液位传感器。
- **控得越稳，产率越高**：机器记录最近一段时间状态偏离设定点的程度，偏离越小，产出越多（例如从 80% 提高到 110%）。不控制也能用，但会亏。

具体的机器和数值见 [`production-ideas.md`](production-ideas.md)。第一批计划：

1. **发酵罐**：入门。温度窗口宽，失败温和（酵母失活，产物变少）。
2. **硝化反应釜**：进阶。放热、会“飞温”，需要比例控制，失败会爆炸，但有泄压阀兜底。

## 进度安排

| GT6 阶段 | 解锁内容 |
|---|---|
| 蒸汽 / 早期 | 指示灯、报警铃、厨房定时器、浮球开关（锅炉补水是 GT6 早期最常见的需求） |
| LV | 恒温器、蓄电池管家、电动阀、发酵罐 |
| MV | 第二档组合元件、调节阀、可调加热器 |
| HV 及以后 | 第三档精细控制元件、硝化反应釜等高级工艺 |

## 帮助玩家上手

- **游戏内手册**：GT6CE 开发环境里装了 GuideME，可以考虑用它做带 3D 场景的手册页。每页从一个具体问题讲起，配一个能直接照搭的示例。
- **元件提示**：鼠标悬停时说明“它解决什么问题”，而不是“它的原理是什么”。
- **复制设置**：用一个工具（类似数据棒）在同类元件之间复制设置，搭大规模产线时不用一个个调。
- **放大镜读数**：用 GT 的放大镜右键任何元件或信号线，显示当前值、设定值和最近的状态。

## 暂不做

- 无线信号、跨维度信号（GT6 已有远距离传输相关的东西，等需求明确再说）。
- 完整的编程方块（类似 OpenComputers / ComputerCraft）。可编程模块只支持一行公式。
- 依赖本体尚未开放的接口的功能，例如读取本体机器的温度和进度。等上游 API 补上再做，见 [`integration.md`](integration.md) 的“需要向上游提的 API”。
