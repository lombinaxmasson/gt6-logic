# GT6 Logic 内容设计

本文是附属本体的设计稿：定位、设计原则、元件清单、进度安排和界面约定。具体产线的点子另见 [`production-ideas.md`](production-ideas.md)，和 GT6CE 的接口约定见 [`integration.md`](integration.md)。

> 2026-10-23 更新：方向收成“GT6 的供给计量层”。GT6 本体负责测量和开关控制，ProjectRed 负责开关量逻辑，本模组只做连续量。工艺机器不再规划；与 GT6 重复的 11 块已按 [`删掉与 GT 重复的方块详细计划`](card-plans/closed/删掉与GT重复的方块详细计划.md) 删除。当前元件见 [`components.md`](components.md)。

## 一句话定位

GT6 Logic 补 GT6 和 ProjectRed 都没有的那一半：**按信号连续变化的执行器、回差、细值读写和连续量运算。**

- 玩家测液位、温度、电量、进度，用 GT6 自己的传感器面板。
- 玩家搭与、或、非、锁存、计时、计数，用 ProjectRed。
- 玩家需要“按比例开阀”“抵消长线衰减”“看清小数”“把细值送进捆绑线缆”时，用本模组。

目标是让 GT6 的自动化更平稳、更精确，同时不增加一套与本体竞争的控制元件。

## 设计原则

### 1. 用生活里的东西命名，不用电路术语

玩家面对的是“调节阀”“比例控制器”“记录仪”，不是“施密特触发器”“RS 锁存器”“单稳态电路”。开关量的门、定时、计数、选择已经交给 ProjectRed；阈值测量和机器开关交给 GT6 的传感器和覆盖板。

### 2. 不重复本体已经做好的事

一个元件要先回答“GT6 或 ProjectRed 做不了吗”。做不了才留：

- GT6 的泵按电压档固定速率，shutter 只有开关。**按信号连续变化的流量**是缺口。
- GT6 的传感器输出 0–15 的整数。**小数**和**长线补偿**是缺口。
- GT6 的六格显示只有当前值。**指针和趋势**是缺口。

### 3. 界面说人话，并且看得见

- 设定值用机器自己的单位，不让玩家去想“7.25 级信号”。
- 需要看精确值时，信号表显示四位小数；需要看趋势时，记录仪保留最近一分钟的最低和最高。
- 方块上的状态要一眼可读：指针表、记录仪、信号表。

### 4. 失败要温和，奖励要明显

- 控制不好时，先是软失败：减产、出副产物、冒烟。
- GT6 已经有压力阀和锅炉危险系统。本模组负责把供给调得更平稳，不是唯一的安全手段。
- 控制得好，机器少停、少冲出去；控制得差也能继续玩。

### 5. 先给需求，再给工具

每个元件都应该在玩家刚好需要它的时候出现。现在还没有配方；把保留的 11 块接进 GT6 的电压档和组装流程，是下一阶段的事。

### 6. 有趣而无害的东西也欢迎

记录仪、指针表让基地看起来像一座真正的工厂。它们不解决问题，但让状态看得见。

## 元件清单

按用途分三组。具体方块和状态以 [`components.md`](components.md) 为准。

### 执行器

| 元件 | 解决的问题 | 吃什么信号 |
|---|---|---|
| 调节阀 | 按信号强度连续调节流量，而不是只有开和关 | 连续信号，满信号每拍 250 mB |
| 可调泵 | 按信号强度连续抽送 | 连续信号，满信号每拍 1000 mB |

### 连续量模块

| 元件 | 解决的问题 |
|---|---|
| 比例控制器 | 偏差越大，调节越猛 |
| 配比控制器 | 让两路流量保持固定比例 |
| 算术模块 | 加、减、缩放、取最大最小 |
| 可编程模块 | 写一行小公式，例如 `clamp(a * 0.5 + b, 0, 15)` |

### 工具与仪表

| 元件 | 解决的问题 |
|---|---|
| 信号表 | 看清 GT 线上的精确值，四位小数 |
| 补偿中继器 | 抵消信号线长距离传输的衰减 |
| 捆绑线缆接口 | 把 GT 细值放进 ProjectRed 捆绑线缆的一种颜色 |
| 指针表 | 一眼看见开多大 |
| 记录仪 | 刚才有没有冲出去，留最近一分钟的趋势 |

## 不做工艺机器

本模组不添加发酵罐、硝化釜或任何额外机器。被控制的对象是 GT6 已有的机器、管道和储罐；本模组只做读值、运算和供给计量。

## 进度安排

| 阶段 | 内容 |
|---|---|
| 现在 | 删除与 GT6 重复的 11 块，保留 11 块 |
| 下一张 | 死区继电器：读红石或 GT 信号，双阈值，输出细值 |
| 之后 | 调节阀/可调泵按供给计量产品化，补扳手接通规则 |
| 再之后 | 把保留的 11 块接进 GT6 的配方与电压档 |
| 最后 | 热量路径，等上游确认 HU/CU 消费者 |

## 帮助玩家上手

- **游戏内手册**：每页从一个具体问题讲起，例如“锅炉补水总是开关太频繁？试试回差继电器”。
- **元件提示**：鼠标悬停时说明“它解决什么问题”，而不是“它的原理是什么”。
- **复制设置**：用一个工具在同类元件之间复制设置。还没有做。
- **放大镜读数**：用 GT 的放大镜右键任何元件或信号线，显示当前值和设定值。

## 暂不做

- 无线信号、跨维度信号。
- 完整的编程方块。可编程模块只支持一行公式。
- 覆盖板形态。附加 SDK 没有接口。
- 依赖本体尚未开放的接口的功能，例如读取本体机器的温度。见 [`integration.md`](integration.md) 的“需要向上游提的 API”。
