## 0. 它解决什么

两路信号要加在一起，或者只留较大的那路。运算在这块上选，不另做六块。

## 1. 行为

- 方块 id：`gt6logic:arithmetic`。朝向那一面是第一路，对面是第二路，其余四面送出结果。两面输入对外都是 0。只实现 `GtSignalSource`。走信号双缓冲。
- 六种运算，默认相加，右键循环：相加、减去、缩小一半、放大一倍、取较大、取较小。减出来的负数夹成 0。一半是整数除法。一倍超过满信号就停在满信号。缩小一半和放大一倍只看正面。
- 句子按运算：英文 `Add` / `Subtract` / `Half` / `Double` / `Larger` / `Smaller`，中文 `相加` / `减去` / `缩小一半` / `放大一倍` / `取较大` / `取较小`。
- 存档记运算名字。不认识的名字回到相加。
- `powered` 在结果向上取整至少 1 级时亮，光照 7。不导电。创造栏图标仍是指示灯。掉落自己。没有配方。
