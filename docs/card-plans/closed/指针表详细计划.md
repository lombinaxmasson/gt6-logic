## 0. 它解决什么

数码管给精确的字。指针表给一眼能看的开度：空、一半、快满。

## 1. 行为

- 方块 id：`gt6logic:pointer_gauge`。只听正面。只实现 `GtSignalReceiver`。会导电，不重写 `getSignal`。
- 0 指在正上方。满信号停在一整圈的 `15.5 / 16`，不和 0 叠在一起。超过满信号的先夹到满信号。
- 空手和放大镜都只报。英文 `Needle %s`，中文 `指针 %s`，数是四位小数。
- 存档记读数。变了才同步。创造栏图标仍是指示灯。掉落自己。没有配方。
