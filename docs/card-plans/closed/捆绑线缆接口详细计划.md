> 性质：GT 线的精细值和 ProjectRed 捆绑线缆的一种颜色互相转换。原版红石只有 0–15，小数从这里走。

## 0. 它解决什么

GT 线进 ProjectRed 时按原版规则向上取整，小数丢掉。液位、温度、电量要精确传送，只能走捆绑线缆：一根线 16 色，每色 0–255。

## 1. 行为

- 方块 id：`gt6logic:bundled_tap`。朝向面贴着 GT 信号线，反面贴着捆绑线缆。
- 右键切换方向：线缆到 GT，或 GT 到线缆。潜行右键轮换 16 种颜色。空着手点报告当前颜色和方向。
- 线缆到 GT：读这一色的 0–255，输出 `值 × 15 UNIT / 255`，经 `GtSignalCarrier.clamp` 夹紧。其余颜色不读。
- GT 到线缆：读 GT 线的 `signal()`，换算成 0–255，只写这一色，其余 15 色为 0。
- 换算写成 `BundledScale`，不依赖游戏。0 对 0，255 对 `15 * UNIT`，中间向下取整，来回转换最多差 1。
- 编译依赖用 ProjectRed core jar 里嵌的 `META-INF/jarjar/mrtjp.ProjectRed-1.21.1-4.23.0-api.jar`。`fetch-projectred.ps1` 下载后把它解出来放到 `libs/projectred/`，`compileOnly` 指向它。接口类是 `mrtjp.projectred.api.IBundledTile`，读线缆用 `ProjectRedAPI.transmissionAPI.getBundledInput`。
- 方块实体实现 `IBundledTile`。`canConnectBundled` 只在反面返回真，`getBundledSignal` 只在 GT 到线缆的方向上返回值。

## 2. 明确不做

- 一块接口同时管多种颜色。要多种颜色就放多块接口，各管一色
- 接口直接贴在机器上读液位或电量。那是机器总线，这轮不做
- 改 ProjectRed 线缆本身的连接规则

## 3. 验收

- [x] `BundledScale`：0、128、255 三个点的换算与夹紧，来回转换的误差不超过 1
- [x] GameTest：GT 线带 `7.5 * UNIT`，接口设为 GT 到线缆、红色，线缆的红色读到 127 或 128，其余颜色为 0
- [x] GameTest：线缆红色为 255，接口设为线缆到 GT，GT 线读到 `15 * UNIT` 减去一格线损
- [x] 潜行右键换色、右键换方向后，上面两条结果跟着变
- [x] `gradlew test` 和 `gradlew runGameTestServer` 通过
