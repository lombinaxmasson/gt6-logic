## 0. 它解决什么

线每过一格减去 `UNIT / range`。长线末端的精细值会矮一截。中继器把刚过去的那一跳加回来。

## 1. 行为

- 方块 id：`gt6logic:compensation_repeater`。朝向只听正面。`powered` 在补回之后向上取整至少 1 级时亮，光照 7。不导电。
- 只实现 `GtSignalSource`。输入那一面对外是 0，其余五面送出补回后的值。走信号双缓冲。
- 补回量是 `UNIT / range`，和线自己用的整数除法相同。结果再用 `GtSignalCarrier.clamp` 夹到 `15 * UNIT`。输入是 0 时输出仍是 0：已经减成 0 的一跳和「没有信号」分不清，不能凭空造出一个信号。
- 距离只有 GT6CE 实际在用的两档：16（红合金、流明）和 64（信素）。默认 16。右键在这两档之间换。放大镜不改。
- 句子：英文 `Restores range %s`，中文 `补回距离 %s`。
- 存档只记距离。不认识的距离回到 16。
- 放下来时朝向贴着点中的那一面。创造栏图标仍是指示灯。掉落自己。没有配方。
- 它不读取线内部的 `loss()`。那个方法不在附属 SDK 里。

## 2. 明确不做

- 界面、配方
- 一次补回好几跳。一格中继器只补一跳
- 把 0 抬成 `UNIT / range`
- 反射去读 GT 的线
