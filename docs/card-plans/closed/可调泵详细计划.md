## 0. 它解决什么

阀的 250 mB 不够快。泵用同一套比例，满开是每拍一桶。

## 1. 行为

- 方块 id：`gt6logic:adjustable_pump`。进出口、信号面、没电就停，都和电动阀一样。
- 满信号每拍 1000 mB。比例同样向下取整。这一拍算出来的流量大于 0 才花 1 EU；流量是 0 不花钱。
- 句子沿用阀的三句。创造栏图标仍是指示灯。掉落自己。没有配方。

## 2. 明确不做

- 加压、扬程
- 不接信号也能转

- [x] 满信号并且有 LV：这一拍要 1000 mB，出口增加的是 1000 的倍数
- [x] 创造栏里能拿到，英文 Adjustable Pump，中文可调泵
