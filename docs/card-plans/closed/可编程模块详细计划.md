## 0. 它解决什么

算术模块的六种不够时，用一行把它们拼起来。不是电脑，没有第二行。

## 1. 行为

- 方块 id：`gt6logic:formula_module`。正面是 `a`，背面是 `b`，两面静音。其余四面送出结果。只实现 `GtSignalSource`。结果夹到 0 和满信号；公式内部可以是负数，上线之前才夹。
- 公式按“级”算。1 级在内部是 10000，所以 `0.5` 乘完是准的。`UNIT` 是奇数，不能用 `UNIT / 2` 代表半级。
- 语法：`+ - * /`、括号、小数、`min`、`max`、`clamp`。`clamp` 的上下限写反了会自己对调。除以 0 得 0。算不出来，或者括号没合上，这一拍输出 0。一行最长 64。嵌套深度 32。
- 右键在四行之间循环，默认第一行：`clamp(a * 0.5 + b, 0, 15)`、`min(a, b)`、`max(a - b, 0)`、`clamp(a * 2, 0, 15)`。当前字符串不在这四行里，下一次右键回到第一行。
- `setFormula` 留给以后的输入界面和测试。这一轮没有打字界面，字符串已经进存档。
- 句子：能算是英文 `Formula %s`、中文 `公式 %s`。不能算是 `Cannot read %s` / `算不了 %s`。放大镜只用 0 和 0 看它能不能解析。
- 创造栏图标仍是指示灯。掉落自己。没有配方。
