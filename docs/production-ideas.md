# 产线与配方点子

这里收集“会需要简单电路”的产线和配方点子。想到新点子就往后加，不用一开始就完整。设计原则见 [`content.md`](content.md)。

## 怎样制造需求

一个点子要让控制元件有用，通常要满足下面几条中的至少两条：

1. **工作区间**：只在某个温度、压力、配比范围内正常工作。
2. **惯性**：状态变化需要时间，停止输入后还会继续变一会儿。这样“到阈值就开关”会来回振荡，回差和比例控制才有意义。
3. **控得好有奖励**：越稳产率越高，或者副产物越少。不控制也能用，只是亏。
4. **有可调的执行器**：调节阀、可调加热器这类“不只有开和关”的东西。
5. **顺序和时间**：步骤必须按顺序做，或者某一步必须持续多久。

## 点子模板

```
### 名字
- 玩法：玩家在做什么
- 跑偏：不控制时会发生什么
- 需要的元件：
- 控得好的奖励：
- 难度：入门 / 进阶 / 高级
- 联动：和哪些附属或本体内容相关
- 待确认：需要核对的本体机制或 API
```

## 入门

### 发酵罐（第一批）
- 玩法：糖、果汁或谷物浆加酵母，发酵成乙醇或酒，副产二氧化碳。
- 跑偏：酵母在 28–35 °C 工作。低于 20 °C 几乎不反应；超过 40 °C 酵母开始失活，产物变少，并出“杂醇油”副产物。发酵本身会缓慢放热，所以夏天（或者炎热生物群系）会自己升温。
- 需要的元件：恒温器 + 加热器 / 冷却阀。也可以只用浮球开关控制进料。
- 控得好的奖励：一直保持在 30–33 °C，产率提高到 110%。
- 难度：入门。失败只是减产，不会出事。
- 联动：gt6-crops 的作物作原料；产出的乙醇可以接燃料发电机（GT6CE 0.7 的燃料表 API）。
- 待确认：GT6CE 里现有的发酵配方（`docs/weekly-audit-fermentation-*`）和本附属的发酵罐怎样区分，避免重复。

### 锅炉补水
- 玩法：给 GT6 的锅炉自动补水。
- 跑偏：水位过低时继续加热锅炉会损坏（待核实本体的具体行为）。一直开着进水又浪费、溢出。
- 需要的元件：浮球开关（低于 30% 开阀，高于 80% 关阀）。
- 控得好的奖励：不用新机制，避免事故本身就是奖励。
- 难度：入门。
- 联动：本体锅炉。不需要任何新机器，是最早能用上本附属的场景。
- 待确认：本体锅炉缺水时的具体后果；本体液位传感器能否读锅炉储罐。

### 蓄电池管理
- 玩法：多台发电机分级启动。电量低于 50% 开第二台，低于 20% 开第三台，充到 90% 后再依次关掉。
- 跑偏：只用一个阈值时，发电机会在临界点附近频繁启停。
- 需要的元件：蓄电池管家（多段回差）。
- 控得好的奖励：省燃料，发电机寿命（如果有磨损机制）。
- 难度：入门。
- 联动：本体电池、燃料发电机。
- 待确认：怎样读本体电池的电量。本体电量传感器只读电线，不读电池（见 `integration.md`）。可能需要我们自己的“电表”方块串在线路上。

### 温室光照
- 玩法：短日照作物只在每天光照少于 12 小时时开花结果。用定时器控制补光灯，在地下农场或任何季节都能让它们结果。
- 跑偏：一直开灯，这些作物只长叶子不结果。
- 需要的元件：厨房定时器（开 10 分钟、关 10 分钟这样的循环）。
- 控得好的奖励：解锁这些作物的产出。
- 难度：入门。
- 联动：gt6-crops，可以给它的作物卡加一个 `photoperiod` 条件。
- 待确认：需要 gt6-crops 提供读取光照条件的扩展点。

## 进阶

### 硝化反应釜（第一批）
- 玩法：甘油或甲苯加混酸，做硝化甘油、TNT 等炸药原料。
- 跑偏：反应强烈放热，而且温度越高反应越快、放热越多（“飞温”）。超过临界温度会爆炸。冷却水开太大，反应又会停掉，酸液被稀释浪费。
- 需要的元件：比例控制器 + 调节阀（温度越高冷却水越大）；泄压阀作为安全装置。
- 控得好的奖励：产率和纯度。纯度高的产物可以做更强的炸药。
- 难度：进阶。有真实的危险，但泄压阀兜底：装上泄压阀后不会爆炸，只会损失整批原料。
- 联动：如果以后做化工附属，硝酸可以从那边来。
- 待确认：本体现有炸药和硝酸相关材料，按名字声明新材料时避免冲突。

### 燃烧配比
- 玩法：燃气锅炉同时进燃料和空气，配比影响效率。
- 跑偏：燃料太多会冒黑烟、积碳（需要停机清理）；空气太多效率低，并产生氮氧化物废气。
- 需要的元件：配比控制器（空气流量 = 燃料流量 × 系数），或者算术模块 + 调节阀自己搭。
- 控得好的奖励：效率从 70% 提到 100% 以上。
- 难度：进阶。
- 联动：GT6CE 0.7 的燃料发电机 API（燃料表、废液罐）。
- 待确认：燃料发电机目前只烧单一燃料流体，要做配比需要自己写方块实体。

### 间歇聚合
- 玩法：进单体 → 加热到反应温度 → 保温一段时间 → 加引发剂 → 冷却 → 出料 → 清洗。
- 跑偏：顺序错了或者保温时间不对，产出低品质的塑料（性能差，或者只能回收）。
- 需要的元件：延时继电器、计数器、程序控温器。也可以用几个定时器串起来。
- 控得好的奖励：高品质塑料，用于高级电路板或特殊外壳。
- 难度：进阶。
- 联动：本体塑料产线。高品质产物只作为可选的升级材料，不替代本体配方。

### 酿酒的糖化
- 玩法：麦芽浆按 52 °C → 63 °C → 72 °C → 78 °C 分段升温，每段保温一段时间。
- 跑偏：跳段或温度不准，出糖率低，酒的品质差。
- 需要的元件：程序控温器；入门玩家可以手动切换几个恒温器。
- 控得好的奖励：高品质酒，GT6 的食物 / 饮料系统里效果更好（待核实本体饮料有没有品质概念）。
- 难度：进阶。偏休闲。
- 联动：发酵罐；本体食物与饮料。

### 酸碱中和
- 玩法：处理酸性废液，加碱中和到中性后才能排放或回收。
- 跑偏：pH 对加碱量非常敏感，接近中性时一点点碱就会冲过头变成碱性。
- 需要的元件：比例控制器 + 小流量调节阀。这是现实里有名的难控场景，适合作为高级挑战。
- 控得好的奖励：回收盐类副产品。
- 难度：进阶到高级。
- 联动：本体化工产线的废液。
- 待确认：本体有没有“废液”概念，是否需要本附属自己定义。

## 高级

### 程序退火
- 玩法：玻璃或特殊合金按温度曲线加热、保温、缓慢降温。
- 跑偏：降温太快会产生内应力，产出“易碎”的次品。
- 需要的元件：程序控温器。
- 控得好的奖励：高级光学玻璃、透镜材料。
- 难度：高级。
- 联动：本体透镜、激光相关产线。

### 空分冷箱启动
- 玩法：低温空气分离装置启动时必须按顺序逐级降温，稳定后再开始出产物。
- 跑偏：启动顺序错了会结冰堵塞，要停机解冻。
- 需要的元件：延时继电器、联锁开关、顺序控制。
- 控得好的奖励：液氧、液氮、稀有气体。
- 难度：高级。
- 联动：本体气体相关配方。

### 蒸馏塔回流
- 玩法：调节回流比，在纯度和产量之间取舍。
- 跑偏：回流太小纯度不够，太大产量太低、耗能太高。
- 需要的元件：调节阀 + 读塔顶温度的读数方块。
- 控得好的奖励：高纯度产品。
- 难度：高级。
- 联动：本体蒸馏塔。
- 待确认：本体蒸馏塔是 GT 内置控制器，附属改不了它的逻辑。可能要做成本附属自己的“精馏柱”。

## 不需要新机器的“小需求”

这些场景在本体里已经存在，本附属的元件可以直接派上用场，适合写进手册当示例：

- **定量出货**：计数器控制传送，每次正好送 64 个给下游。
- **顺序开机**：大型多方块按顺序启动，避免同时启动时电网瞬间过载。
- **满仓停机**：输出箱快满时停掉上游机器，箱子空了再开。
- **夜间模式**：晚上关掉高耗电机器，白天太阳能发电时再开。
- **控制室**：把整个基地的状态拉到一面墙上，用指示灯和数码管显示。纯观赏，但很有成就感。

## 有趣而无害的东西

- 报警铃、汽笛，可选音色。
- 警示灯塔，不同颜色代表不同状态。
- 大号拉杆、带标签的按钮。
- 记录仪：界面里画出长时间曲线，像真的纸带记录仪。
- 数码管显示屏：显示任意信号线的数值。
- “紧急停止”大红按钮：一按整片区域的机器都停。

## 想法暂存

还没想清楚，先记下来：

- 机器有“磨损”，频繁启停会加速磨损，给回差控制一个额外的理由。
- 天气和季节影响温度：夏天发酵罐更容易过热。
- 多人服务器上，控制室面板可以设置权限，只有工程师能改设定值。
- 成就系统：“第一次让机器稳定运行 1 小时不越线”。
